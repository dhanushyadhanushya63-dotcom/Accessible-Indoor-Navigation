# WCAG 2.1 AAA Accessibility Guidelines

Design system compliant with universal access principles for users with visual, motor, or cognitive impairments.

## Contrast Specs
- Background: Deep Obsidian (#000000 / #0a0a0a)
- Text: Stark White (#ffffff) with 21:1 contrast ratio
- Interactive Focus: Electric Amber (#facc15) outline ring
- Typography Scaling: 115% enlarged font mode
