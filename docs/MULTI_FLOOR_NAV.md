# Multi-Floor Vertical Transit Navigation

Floor-to-floor indoor navigation with vertical transit nodes (Elevator A, Central Stairwell).

## Supported Levels
- **Level 0 (Ground Floor):** Main Entrance, Reception, Classrooms 101-103, CS Lab, Library, Seminar Hall
- **Level 1:** Advanced Robotics Lab, Faculty Offices, Lecture Halls 201-205
- **Level 2:** Research Center, Quiet Study Lofts, Rooftop Observatory
