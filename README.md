# Accessible Indoor Navigation and Obstacle-Aware Route Planner

Premium, modern, highly interactive web application for accessible indoor navigation and obstacle-aware route planning in campus buildings.

## Key Capabilities
- **Interactive 2D Vector SVG Floor Map:** Architectural floor plan with zoom, pan, clickable rooms, and neon path drawing.
- **Multi-Criteria Dijkstra Routing:** Step-free, wheelchair-friendly, and obstacle-aware path calculations.
- **Real-Time Obstacle Management:** Corridor block/unblock toggles with instant live route recalculation.
- **Speech Synthesis Guidance:** Vocal turn prompts for visually impaired navigators.
- **WCAG 2.1 AAA Accessibility:** High contrast mode, larger text option, and ADA compliant ramp slope tolerances.

## Technology Stack
- HTML5, CSS3, JavaScript ES6
- Bootstrap 5 & Lucide Icons
- Client-Side LocalStorage Persistence

## Running the Project
```bash
node server.js
```
Open http://localhost:3000 in your browser.
